# Real-Time Text Search & Pattern Matching Tool

A Python desktop application that demonstrates and compares string-searching algorithms through a graphical user interface.

## Features

- Real-time text and pattern searching
- Naive String Matching
- Knuth–Morris–Pratt (KMP)
- Rabin–Karp
- Regular Expression (Regex) matching
- Case-sensitive and whole-word search options
- Search history
- Export results to TXT and CSV
- Performance comparison graph

## Technologies

- Python
- Tkinter
- Regular Expressions
- CSV

## How to Run

1. Install Python 3 on your computer.
2. Download this repository.
3. Open the `Real_Time_Text_Search` folder in a terminal.
4. Run:

```bash
python main.py
```

Install any additional libraries required by the application before running it.
